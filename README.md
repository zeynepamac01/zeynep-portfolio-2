# Zeynep S. Amac — Engineering Portfolio

This is a new React/Vite portfolio project based on the Professional Engineering Portfolio design. It incorporates the project evidence, experience, education, involvement, skills, contact links, CV, and project imagery from the earlier static portfolio.

## Run locally

Install dependencies with `pnpm install`, then run `pnpm dev`.

## Content and assets

- `src/App.tsx` contains the portfolio sections and content.
- `src/index.css` contains the site styling.
- `public/legacy/` contains copied portfolio images, PDFs, and project/ethics detail pages needed by links in the new site.

The original source folders were not edited.
